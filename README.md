# Студия детских праздников «Фиестас»: новый сайт

Аниматоры, шоу-программы, аквагрим, шары и торты. Минск и область.
Чистый HTML, CSS и JS без сборки и зависимостей.

## Страницы

| Файл | Что внутри |
| --- | --- |
| `index.html` | Главная: поводы, четыре программы, персонажи, шоу, отзывы |
| `animatory.html` | 40 персонажей с ценами: дуэты, соло, компании |
| `shows.html` | Девять шоу-программ с длительностью и стоимостью |
| `programmy.html` | Бронза, серебро, золото, платина: что входит |
| `uslugi.html` | Аквагрим, торт, пиньята, шары, съёмка, прайс |
| `meropriyatiya.html` | День рождения, выпускной, Новый год, корпоратив |
| `otzyvy.html` | Отзывы родителей со старого сайта |
| `kontakty.html` | Адрес, телефоны, часы, форма заявки |
| `politika.html` | Политика обработки данных |

## Как собрано

Страницы генерируются из шаблона скриптом `build.py`: шапка, подвал, меню и метаданные
не разъезжаются при правках. Правьте текст в `build.py`, затем:

```bash
python3 build.py
```

## Данные взяты с fiestas.by

Телефоны, адрес, часы работы, цены на аниматоров и программы, отзывы перенесены с
текущего сайта студии. Ничего не придумано. Там, где на старом сайте цены не указаны
(бумажное, поролоновое, серебряное, мультиколор, золотое шоу, шар-сюрприз, оформление),
написано «цену уточняем».

## Что заменить перед запуском

1. **Фотографии.** Снимки в `assets/img/` взяты с fiestas.by. Для нового дизайна нужны
   свежие кадры в высоком разрешении: герой вертикальный 1:1, поводы 3:4, шоу 16:9.
   Названия файлов лучше сохранить, тогда вёрстка не поедет.
2. **Вырезанные персонажи.** `char-*.png` с прозрачным фоном: это те же снимки, из которых
   удалён фон. Если появятся новые костюмы, вырезать по такому же принципу.
3. **Политика.** В `politika.html` и в `build.py` указан оператор. Проверьте, нужны ли
   УНП и юридический адрес.
4. **Заявки.** Форма собирает текст и открывает WhatsApp с готовым сообщением. Чтобы
   заявки приходили на почту, подключите Formspree или Getform рядом с `wa.me` в
   `assets/js/main.js`.

## Домен

Сайт в корне репозитория, адрес: `https://romjjjke.github.io/fiestas/`.
Свой домен: Settings → Pages → Custom domain, файл `CNAME`, DNS у регистратора.

## Проверки

- нет горизонтального скролла на 1440, 1200, 1100, 1024, 768, 390 и 360 px
- контраст текста не ниже 4.5:1, малиновый затемнён до #C9185C ради этого
- меню, аккордеон и форма проверены в браузере: валидация, сборка сообщения, возврат к правке
- изображения с указанными размерами, ленивая загрузка вне первого экрана
